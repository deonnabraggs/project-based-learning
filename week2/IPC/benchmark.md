# Benchmark – Time Analysis

## Test Case

Instruction: ADD  
Value 1: 5  
Value 2: 7  

Expected Result: 12

## Benchmark Result

| Run | Instruction | Input | Execution Time |
|-----|-------------|-------|----------------|
| 1 | ADD | 5 + 7 | 46.55 seconds |

## Observation

The program successfully accepted the ADD instruction and input values.

The measured real execution time was **46.55 seconds**.

The execution time was measured using the Linux `time` command.
